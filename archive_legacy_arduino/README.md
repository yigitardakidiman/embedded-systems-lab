# 🗄️ Eski Projeler Arşivi (Legacy Arduino Smoke Test Archive)

Bu dizin, laboratuvardaki geliştirme kartlarının ilk elektriksel doğrulaması (Smoke Test) amacıyla `Arduino.h` framework'ü kullanılarak tamamlanmış olan ilk aşama projelerini, devre fotoğraflarını ve video kayıtlarını barındırır.

Laboratuvar genelinde **saf doğal ekosistemlere (Native SDK / STM32Cube HAL / ESP-IDF / Pico SDK / AVR Bare-Metal)** geçiş kararı alınmasıyla birlikte, bu projeler tarihsel referans ve görsel kanıt olarak bu arşive taşınmıştır.

---

## 📂 Arşiv İçeriği

* **01_ESP_WROOM_32:** P1 (Blink & Boot Button), P2 (Capacitive Touch LED Bar)
* **02_RPi_Pico_2_W:** P1 (Blink & CYW43), P2 (Hardware PWM Slice Breathe LED)
* **03_CRIUS_ATmega2560:** P1 (AVR Register Blink & Timer1 CTC)
* **05_TI_MSP430F5529_LP:** P1 (UCS 25MHz Dual Port Blink)
* **06_TI_TM4C123GXL_TivaC:** P1 (RGB Blink & PF0 Unlock)
* **07_ST_NUCLEO_U575ZI_Q:** P1 (SMPS Power & BSRR Blink)
* **08_ST_P_NUCLEO_WB55:** P1 (Dual-Core HSEM & Dongle Blink)
* **09_ST_NUCLEO_H723ZG:** P1 (M7 550MHz D-Cache Clean Blink)
